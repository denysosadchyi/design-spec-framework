# Wireframe conventions

<!-- the written contract every fan-out subagent reads before touching a screen -->

## File naming

- Default state: `wireframes/<screen>.html`
- Other states: `wireframes/<screen>-empty.html`, `-error.html`, `-loading.html`

## Markup rules

- Semantic HTML only, no visual styling beyond grey wireframe boxes.
- Real domain copy — no lorem ipsum, no placeholder brand names.
- Every interactive element is a real `<a href>` or `<button>`, wired to its target screen.
