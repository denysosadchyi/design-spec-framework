# Visual references

**A reference is an input, not an output.** No source is copied whole: one is the **base**,
and 1–2 **concrete devices** are borrowed from the others. Not "the general feel" — a device:
the card radius, where the badge sits, how much colour appears on one screen.

`research/research.md` already names the benchmark dimension this product is measured against.
**Do not run a new competitor search** — look for their *visual* language.

Collect **3 to 5 sources in total**: 3–4 **styles** matching a query built from the product's
positioning and audience, and 2–3 **screens** matching the specific device this product must
get right, on the target platform. Pull the full data for the two or three strongest.

Record the source method per row — Refero MCP if the toolbox says it is active, otherwise web
search plus screenshots saved into `research/screens/`.
