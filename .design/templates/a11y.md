# Accessibility checklist

**A consolidation, not a work plan.** This file proves that accessibility is already built into
the system by phases 4–9, and maps where. **Nothing new is introduced here.** If the
consolidation turns up a hole, it does **not** get fixed in this phase: it becomes a debt row in
`handoff/onboarding-gaps.md`, and the item is marked `open` below.

Every row names **where it lives in the code** (file and selector) and **how to verify it** —
so the next person can re-run the check without asking anyone.
